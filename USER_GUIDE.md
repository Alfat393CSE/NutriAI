## 🌓 Dark Mode

**Toggle dark mode for comfortable viewing in any lighting condition**

### How to Use:
1. Click the **moon/sun icon** in the bottom-right corner
2. Or press **Ctrl/Cmd + Shift + D** on your keyboard

### Features:
- Your preference is automatically saved
- Respects your system's dark mode setting
- Smooth transitions between themes
- Optimized for both light and dark environments

---

## ⌨️ Keyboard Shortcuts

**Navigate faster with keyboard shortcuts**

### Available Shortcuts:

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Open Quick Search |
| `Ctrl/Cmd + B` | Go to Dashboard |
| `Ctrl/Cmd + Shift + A` | Quick Add Food |
| `Ctrl/Cmd + Shift + D` | Toggle Dark Mode |
| `Esc` | Close Any Modal |

### Tips:
- Shortcuts work on any page
- Mac users: Use `Cmd` instead of `Ctrl`
- Shortcuts are case-insensitive

## 🔍 Quick Search

**Find anything instantly**

### How to Use:
1. Press **Ctrl/Cmd + K** anywhere in the app
2. Start typing:
   - Page names (e.g., "dashboard", "meal planner")
   - Food names (e.g., "chicken", "apple")
3. Click any result to navigate instantly

### What You Can Search:
- All app pages and features
- Food database (25+ foods)
- Navigation shortcuts

## 📥 Export Your Data

**Download your nutrition data for analysis**

### Available Exports:

#### 1. Nutrition Data (Dashboard)
- Click **"Export Data"** button on Dashboard
- Downloads CSV with all your food logs
- Includes: dates, foods, meals, calories, macros

#### 2. Meal Plans (Dashboard)
- Available when you have an active meal plan
- Exports your 7-day meal schedule
- Includes nutritional breakdown per meal

#### 3. Activity History (History Page)
- Click **"Export CSV"** on History page
- Downloads your activity log (90 days)
- Includes: searches, views, recommendations

### Using Exported Data:
- Open CSV files in Excel, Google Sheets, or Numbers
- Analyze your nutrition trends
- Share with healthcare professionals
- Create custom reports

## 📱 Install as App

**Use NutriAI like a native app on your device**

### How to Install:

#### On Desktop (Chrome/Edge):
1. Look for the **"Install App"** button
2. Click it and confirm installation
3. App will open in its own window
4. Access from your desktop/start menu

#### On Mobile (Chrome/Safari):
1. Open the menu (⋮ or share icon)
2. Select "Add to Home Screen"
3. Confirm and add icon
4. Launch from your home screen

### Benefits:
- Works offline (cached data)
- Faster loading times
- Native app experience
- No browser UI clutter
- Push notifications (coming soon)

## 🔧 Troubleshooting

### Dark Mode Not Working?
- Check browser supports CSS variables
- Clear browser cache
- Try different browser

### Keyboard Shortcuts Not Working?
- Make sure you're not in an input field
- Check browser shortcuts aren't conflicting
- Try refreshing the page

### Export Not Downloading?
- Check popup blocker settings
- Ensure you have data to export
- Try different browser

### Can't Install as App?
- Use Chrome, Edge, or Samsung Internet
- Firefox doesn't support PWA install (browser limitation)
- Make sure you're on HTTPS (localhost is OK)
